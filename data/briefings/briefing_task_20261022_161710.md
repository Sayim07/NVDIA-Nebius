

**Executive Summary**  
The AgentX Sandbox (Project Titan) currently runs a mixed Python/Node stack. All declared dependencies are within their respective maintenance windows and no active CVE advisories were detected for the exact versions in use during the live Tavily scan (2026‑08‑27). The only notable external intelligence relates to a Fortinet SSO zero‑day (CVE‑2026‑24858) and a MongoDB DoS issue (CVE‑2026‑13070), neither of which affect the project’s direct dependencies. Consequently, the immediate risk posture is **low**, but the weekly CVE verification cadence for PyJWT and Next.js (as noted in the security notes) should be maintained.

### 3. Mandatory Rollback Plan  

**Trigger Conditions**  
1. **CVE Detection** – A newly published CVE (≥ CVSS 7.0) matches any exact version in `backend/package.json`, `contracts/package.json`, or `frontend/package.json`.  
2. **Build/Test Failure** – CI pipeline fails due to a dependency‑related security scanner alert (e.g., `npm audit`, `pip-audit`, `snyk`).  
3. **Runtime Anomaly** – Observed exploitation attempts (WAF/IDS alerts) correlated with a dependency (e.g., JWT token manipulation, Next.js SSR injection).  

**Rollback Procedure**  

| Step | Action | Owner | Estimated Time |
|------|--------|-------|----------------|
| 1 | **Immediate Isolation** – Tag the current release as `rollback-candidate` and prevent further promotion to staging/production. | Release Engineer | 5 min |
| 2 | **Identify Baseline** – Retrieve the last known‑good commit (from `last_audit: 2026-10-10` or the most recent green CI run) that contains the prior dependency lockfiles (`package-lock.json`, `requirements.txt`/`poetry.lock`). | DevOps / Lead Engineer | 10 min |
| 3 | **Revert Lockfiles** – Checkout the baseline lockfiles and overwrite the current ones in the repo. | DevOps | 5 min |
| 4 | **Re‑install Dependencies** – Run `npm ci` (frontend/contracts) and `pip install -r requirements.txt` (backend) in a clean environment. | Build Engineer | 10 min |
| 5 | **Run Security Scan** – Execute `npm audit --production`, `pip-audit`, and `snyk test`; confirm zero findings ≥ CVSS 7.0. | Security Engineer | 15 min |
| 6 | **Execute Smoke Tests** – Run unit, integration, and contract tests against the reverted build. | QA Lead | 20 min |
| 7 | **Promote to Staging** – Deploy the rolled‑back artifact to `https://titan-internal-staging.company.io` and run health‑check endpoints. | Release Engineer | 10 min |
| 8 | **Stakeholder Notification** – Email lead maintainer (Sayim) and post a brief incident summary in the #security‑ops Slack channel. | Incident Commander | 5 min |
| 9 | **Post‑mortem** – Document the CVE that triggered the rollback, mitigation applied, and update the weekly CVE verification checklist. | Lead Engineer | 30 min (after incident) |
